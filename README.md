One line of famous last words, carved as a tombstone epitaph — an entry for
the [make.fun bounty "Famous Last Words: The Funniest Epitaph"](https://make.fun/bounty/u-riidzhsn-famous-last-words-the-funniest-epitaph-ff177406).

## Run

```sh
python3 main.py
```

`main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `/output/entry.txt`), then reads the file back to verify
it round-trips exactly.

## The line

> My doctor gave me a year to live. Turns out he was an optimist.

A year to live, and the doctor still overshot — the optimist in the story
is the one who got the prognosis wrong.
